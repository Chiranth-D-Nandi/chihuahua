Metrics & Abbreviations Glossary

  • ISR (Injection Success Rate): % of inputs that successfully force the VLM to execute the target tool.
  • SSIM (Structural Similarity Index Measure): Visual similarity between clean and poisoned image (1.0 = identical).
  • SDS (Semantic Drift Score): Cosine distance between embeddings of clean vs. poisoned outputs.
  • CLPR (Caption-Label Pearson Correlation r): Correlation between perturbation budget (epsilon) and ISR.
  • ICS (Intent-Call Similarity): B3 Guard Layer 1 cosine score measuring user intent vs. tool description.
  • ASV (Argument Semantic Validation): B3 Guard Layer 2 check validating argument content vs. declared semantic roles.
  • BSD (Baseline Score Drift): B3 Guard Layer 3 percentile monitor tracking score deviation from clean baselines.
  • TCIV (Tool Call Integrity Verifier): B4 3-layer verifier enforcing tool whitelists, schemas, and HMAC signatures.
  • ADR / AER (Attention Deviation / Entropy Ratio): B2 metrics tracking abnormal transformer attention concentration and distribution.
  • CPR / CBD (Context Poisoning Rate / Backdoor Depth): R5 metrics measuring worm propagation rate and hop depth through agent memory.
  • SBI (Structural Boundary Index): Minimal perturbation budget required to trigger tool-call flipping.
  • FGSM / PGD (Fast Gradient Sign Method / Projected Gradient Descent): Single-step and multi-step iterative pixel attack algorithms.
  • SPECTRE (Backdoor Scanner): B0 pre-deployment backdoor scanner using activation clustering and STRIP.
  • Honeypot Agent: B5 decoy agent monitoring worm propagation without executing external tools.

Benchmark Parameters

  • R0 Backdoor: Alpha opacity = 1.0 (Opaque Trigger)
  • R1 Pixel Sweep: Epsilon budgets = [1/255, 2/255, 4/255]
  • R2 Attention: PGD Steps = 100, Target = Entropy Minimization
  • Live Pipeline: Epsilon = 8/255 (FGSM/PGD default)
  • B4 TCIV: 3-Layer Check (Whitelist, Schema, HMAC)
  • B5 Honeypot: N_hops = 5 (Max Propagation Depth)
⚠️ Why are B0, B1, and B3 missing from this list? Modules B0 (Neural Cleanse), B1 (Image Sanitizer), and B3 (Semantic Guard) do not have standalone benchmark cards because they cannot be evaluated in isolation:

• B0 is evaluated jointly within the R0 Backdoor benchmark (it scans the poisoned weights generated by R0).
• B1 and B3 are passive, dynamic guardrails that operate natively within the Live Pipeline Runner (they do not output standalone anomaly scores).
